# Notification sounds

Put sound files for new mail into this folder (`.ogg`, `.mp3`, `.wav`, `.m4a`, `.opus`, up to 3 MB), for example `ciegolink-1.ogg` to `ciegolink-4.ogg`.

- The file name is the display name; hyphens and underscores become spaces.
- Select them in **Settings → Notifications** (default sound and per account).
- Custom sounds can also be placed in the user folder (`~/.config/agenoras/sounds/` on Linux).

**Sent sound:** place `sentMail_Ding.wav` here. If it is missing, a built-in chime plays instead. Select it in **Settings → Notifications → Sound when sending**.
